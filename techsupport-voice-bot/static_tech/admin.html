Knowledge Base Vector Pipeline

Sync, stage, tokenize, and re-index external multi-structured structural nodes.

On — every question searches the knowledge base first. Chunks scoring at or above the relevance floor are treated as authoritative and the answer is built from them. Only when nothing clears the floor is the model allowed to answer from its own general knowledge, and it is told to say that is what it is doing.
Off — whatever the search returns is passed along as optional background and the model answers however it likes.

0.35 suits most knowledge bases. Raise it if the bot leans on loosely related material, lower it if it falls back to general knowledge too readily. The Search Test tab scores real questions against this floor, so you can see what clears it before changing it.
