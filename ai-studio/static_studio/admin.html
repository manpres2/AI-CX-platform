GPT AI Chat

Ask questions to a local or cloud model, the same way you'd chat with Claude — pick the model and, for local models, whether it runs on CPU or GPU.

Type a model name, or paste a full ollama pull … command. Once it finishes it shows up in the Model dropdown below, ready to test.

Agentic AI

A model that can take actions on this machine on your behalf — reading/writing files and running commands — once you explicitly delegate system access. Every action is checked against a safety tier: safe actions run automatically, risky ones wait for your approval, and destructive actions are always blocked.

⚠ System access is delegated. The agent can run shell commands and write files inside the workspace below. Safe actions run automatically; risky actions still need your approval; destructive commands are always blocked.
