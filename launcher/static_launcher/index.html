Create New Bot

Spins up a genuinely new bot — its own port, its own process, its own admin panel. Fine-tune knowledge base, guardrails, and voice afterward in that bot's own admin panel.

⚠ This machine's GPU has 8GB VRAM, already well used by the two built-in bots. Running 3+ live voice bots at once may cause slowdowns or crashes — "Small" reduces that risk. You can change this later in the new bot's own admin panel.

💬 Chat bots skip Whisper (speech-to-text) and Kokoro (text-to-speech) entirely — no mic, no audio, no GPU spent on either — so they're a lighter way to try out a bot config or serve a text-only use case.
