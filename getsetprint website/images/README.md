# Product images

Drop a photo here named to match a product's `"image"` path in `../products.json`
(e.g. `wyrmling-dragon.jpg` for the product with `"id": "wyrmling-dragon"`).

- Until a file exists at that path, the site automatically falls back to a
  placeholder icon — nothing breaks if you add a product before its photo.
- Any common web image format works (`.jpg`, `.png`, `.webp`).
- Recommended size: roughly square, at least 800×800px.
